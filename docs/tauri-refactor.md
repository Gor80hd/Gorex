# Gorex 3: структура приложения

Работа ведётся в `codex/Tauri2`. Основные команды npm теперь запускают Tauri; команды Electron сохранены с суффиксом `:electron`, пока не завершена проверка паритета.

## Rust

| Модуль | Ответственность |
| --- | --- |
| `queue.rs` | Запуск пакета заданий, состояния и прогресс, пауза/остановка, восстановление UI, удаление завершённых записей |
| `jobs.rs` | Реестр дочерних процессов, чтение вывода, сигналы всему дереву, завершение и отмена |
| `encoding.rs` | Аргументы FFmpeg, кодеки, фильтры, пути результата |
| `downloads.rs` | yt-dlp + Deno, форматы, субтитры, скачивание и конвертация |
| `twitch.rs` | Twitch URL, VOD/клипы, качества, чат и экспорт |
| `workspace.rs` | Изолированные временные папки задания и очистка при любом выходе |
| `settings.rs` | Один версионированный файл настроек Tauri |
| `media.rs`, `player.rs` | Метаданные локальных файлов, предпросмотр и изолированный YouTube-плеер |
| `extension.rs` | Прежний HTTP-контракт расширения и выдача локального видео с Range |
| `platform.rs`, `auth.rs`, `updater.rs` | Окна, меню, трей, cookies WebView и обновления инструментов |

`start_queue` принимает все задания пакета. Rust владеет их жизненным циклом; React получает `queue-state` со счётчиком ревизии и отбрасывает запоздавшие события. После остановки пакет остаётся активным, пока все операции не завершили очистку. Новый запуск и команды управления сериализованы, поэтому новый пакет не может попасть под отмену предыдущего.

Метаданные задания доступны при получении исходного снимка, чтобы восстановить очередь после перезагрузки WebView. События прогресса передают только состояние: массивы форматов не сериализуются на каждом фрагменте stdout.

При выходе приложение останавливает задания и ожидает очистку. На Unix пауза/возобновление применяются к группе процессов; остановка начинает с SIGTERM и при необходимости переходит к SIGKILL. Windows управляет деревом процессов через штатные средства ОС. Выходные имена резервируются атомарно: параллельные задания с одинаковым именем получают разные пути, отмена удаляет только собственный незавершённый файл. Временные файлы YouTube и Twitch размещены в отдельных папках; готовые файлы перемещаются в выбранный каталог.

## React / TypeScript

| Модуль | Ответственность |
| --- | --- |
| `domain.ts`, `queueState.ts` | Общие типы настроек, медиа и состояний задания |
| `desktopClient.ts` | Типизированный клиент команд с подменяемым транспортом и корректной отпиской |
| `desktopBridge.ts` | Подключение клиента к Tauri |
| `features/queue/useJobQueue.ts` | Проекция Rust-очереди, управление заданиями, журнал и ошибки |
| `features/queue/jobRequests.ts` | Преобразование задач интерфейса в команды Rust |
| `features/queue/useDownloadQueue.ts` | Получение метаданных, выбор формата и подготовка загрузок |
| `features/twitch/useTwitchChat.ts` | Просмотр, загрузка и экспорт чата |
| `features/tools/useToolUpdates.ts` | Общая логика обновлений yt-dlp и TwitchDownloaderCLI |
| `features/encoding/encodingOptions.ts` | Общие таблицы аудиокодеков и возможностей кодирования |
| `pages/ListPage/listModel.ts` | Форматы, качества и подписи очереди |
| `pages/ListPage/TimeRangeSelector.tsx` | Предпросмотр и редактирование диапазона |
| `pages/ListPage/VideoSettingsPanel.tsx` | Настройки одного задания |
| `pages/SettingsPage/useSettingsPage.ts` | Настройки, GPU, cookies, сохранение и проверка обновлений приложения |
| `pages/SettingsPage/SettingsRows.tsx` | Общие элементы формы |
| `App.tsx` | Сборка экранов, настройки оформления и подключения к системным событиям |

JSX-модулей в renderer больше нет. TypeScript работает в строгом режиме. SCSS, тексты и разметка сохранены. Небольшие общие `.mjs`-алгоритмы пока используются также сравнительным Electron-кодом и его тестами.
